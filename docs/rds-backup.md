# RDS 스냅샷 복원 경험

RDS PostgreSQL을 스냅샷에서 복원한 뒤, 새로운 DB 엔드포인트를 확인하고 WAS의 FastAPI 접속 설정을 조정했습니다. `jlpt-app.service` 재시작 후 웹사이트의 단어 조회가 정상 동작하는 것을 확인했습니다.

## 학습한 점

- 스냅샷 복원은 일반적으로 새로운 DB 인스턴스를 생성하며 기존 애플리케이션의 연결 주소는 자동 변경되지 않습니다.
- 새 인스턴스의 엔드포인트, DB 인증 정보, VPC 보안 그룹(5432)을 확인해야 합니다.
- 스냅샷 이후 생성된 데이터는 해당 스냅샷에 포함되지 않습니다.

## 추후 확인할 항목

자동 백업 보존 기간, 백업 창, 복구 시점, 스냅샷별 비용 및 복구 시간 측정은 추후 문서화할 예정입니다.
